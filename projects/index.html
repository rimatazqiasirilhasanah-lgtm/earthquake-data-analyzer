About The Project

Earthquake Data Analyzer is a project developed to process, analyze, and visualize earthquake data, with a focus on the Bandung area during 2024–2026.

Project Objectives

  • Process and organize earthquake datasets.
  • Analyze earthquake magnitude and depth.
  • Explore earthquake distribution around Bandung.
  • Present data through tables and visualizations.

Methods & Tools

  • Python programming language
  • Pandas and NumPy for data processing
  • Data cleaning and classification
  • Data visualization
  • Streamlit for the interactive application
